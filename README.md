# Customer Shopping Behaviour Analysis

## Project Description

This project focuses on analysing customer shopping behaviour to understand purchasing patterns, customer preferences, product performance, and subscription trends.

The project follows an end-to-end data analytics workflow using Python for data preparation, SQL for business analysis, and Power BI for data visualization and dashboard development.

## Project Purpose

The main objective of this project is to analyse customer shopping data, identify purchasing trends, understand customer preferences, and generate insights that can help businesses improve customer engagement, marketing strategies, and product decisions.

## Tech Stack

- **Python:** Pandas, data exploration and data preparation
- **SQL:** Data analysis and business queries
- **PostgreSQL:** Database management
- **Power BI:** Interactive dashboards and data visualization

## Dataset Information

- **Dataset Name:** Customer Shopping Behavior
- **File Name:** `customer_shopping_behavior.csv`
- **Total Records:** 3,900
- **Original Columns:** 18

The dataset contains customer demographic information, purchased products, product categories, purchase amounts, locations, seasons, review ratings, discount usage, subscription status, shipping types, payment methods, and purchase frequency.

## Features / Highlights

### Python – Data Preparation

- Explored the dataset using Pandas.
- Identified missing values in the dataset.
- Applied a median-based approach to fill missing review ratings by product category.
- Standardized column names for easier analysis.
- Created age groups for customer segmentation.
- Converted purchase frequency into days.
- Checked for duplicate information between discount and promotional code columns.
- Removed the redundant `promo_code_used` column.

### SQL – Data Analysis

Performed SQL analysis to answer 10 business questions:

- Analysed revenue generated by male and female customers.
- Identified customers who used discounts but spent above the average purchase amount.
- Found the top five products based on average review ratings.
- Compared average purchase amounts between Standard and Express shipping.
- Compared spending and revenue between subscribers and non-subscribers.
- Identified products with the highest discount usage.
- Segmented customers into New, Returning, and Loyal categories.
- Identified the top three most purchased products within each category.
- Analysed repeat buyers based on subscription status.
- Evaluated revenue contribution across different age groups.

### Power BI – Dashboard Development

- Developed an interactive Customer Shopping Behaviour Dashboard.
- Created KPI cards to display key customer and purchase metrics.
- Analysed revenue across product categories and age groups.
- Visualized customer subscription status.
- Compared customer counts across different age groups and product categories.
- Added interactive slicers for Gender, Category, Subscription Status, and Shipping Type.

## Key Business Questions

1. Which gender generates more revenue?
2. Which customers use discounts but still spend more than the average purchase amount?
3. Which products have the highest average review ratings?
4. How do average purchase amounts differ between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest percentage of purchases with discounts?
7. How can customers be segmented into New, Returning, and Loyal categories?
8. What are the top three most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. Which age groups contribute the most revenue?
